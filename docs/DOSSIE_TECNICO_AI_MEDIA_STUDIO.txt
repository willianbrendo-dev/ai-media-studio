SUMÁRIO EXECUTIVO
-----------------
O AI Media Studio é um pipeline de produção de micro-séries (novelas regionais)
totalmente automatizado, operando em arquitetura híbrida VPS + Colab GPU L4.
O sistema cobre: geração de roteiro com estrutura dramática viral (4 cortes),
direção de cena Clean Cinema (shot-reverse-shot, OTS, reaction close-up, ensemble),
síntese de voz com sotaque nordestino (Seed-VC + Edge-TTS), animação labial
(EchoMimicV3 / LTX-Video 2.5 22B distilled via WanGP), geração de Production Pack
para Google Flow Veo 3.1 (Ingredients to Video), e costura final com L-cuts
e normalização de áudio 48kHz Stereo SoXR.

class AnimateSceneReq(BaseModel):
    image_b64: str                    # Keyframe base64 (Ingredient/Reference)
    audio_b64: str                    # WAV 48kHz base64 (TTS regional)
    prompt: str                       # Prompt final (veo_prompt + video_cue + wardrobe_ref)
    backend: str = "auto"             # Modelo WanGP (ltx2_25_22B_distilled, etc.)
    width: int = 1080
    height: int = 1920
    fps: int = 24
    steps: int = 8
    guidance_scale: float = 3.5
    duration_sec: float = 3.2
    seed: int = 42
    negative_prompt: str = ""
    # CAMPOS NOVOS (v4.0.3) — injetados pelo vps_novela_runner:
    video_cue: str = ""               # Cue de movimento/câmera (ex: "Medium-wide 35mm...")
    wardrobe_ref: str = ""            # Referência de figurino (ex: "young Latina bride...")

FLUXO DE DADOS — RENDER MODE COLAB_GPU
--------------------------------------
1. Painel recebe POST /api/quick/novela (QuickNovelaRequest)
2. _execute_novela_job() → _invoke_novela_cli() → subprocess vps_novela_runner.py
3. vps_novela_runner.render_novela_episode():
   a. Compila turns (diálogo + emoção + shot_framing sequencial OTS→revOTS→reaction→ensemble)
   b. Para cada turn: sintetiza voz (rve.synthesize_line) → WAV 48kHz
   c. Gera keyframe via Flux (NVIDIA API) ou usa placeholder
   d. Chama _call_colab_animate_take() para cada take:
      - Monta full_prompt = f"{video_cue}. {wardrobe_ref}. {veo_prompt}"
      - POST /jobs/animate_scene {image_b64, audio_b64, prompt, backend, ...}
      - Poll GET /jobs/{job_id} a cada 3s (max 300s)
      - Recebe video_b64 → decodifica → MP4 local
   e. Stitch final: concatena takes com L-cuts (lead_in_pause, l_cut_bleed_sec)
   f. FFmpeg mux: vídeo (copy) + áudio master (AAC 192k 48kHz stereo)
   g. Retorna JSON com metadata (duration, shot_framings, engines_used, etc.)

SHOT FRAMING SEQUENCE (VIRAL_4_CUTS)
------------------------------------
Turn 1: over_shoulder          (50mm, OTS eixo direito)     ~3.2s  — Hook/Confrontação
Turn 2: reverse_over_shoulder  (50mm, Contraplano eixo esq) ~3.2s  — Resposta
Turn 3: reaction_closeup       (85mm, Close-up choque)      ~1.5s  — Reação silenciosa
Turn 4: wide_ensemble          (35mm, Ensemble cliffhanger) ~2.0s  — Contexto social

Eyeline Locking (Regra 180°):
- Personagem A: eyeline_side = "off_camera_right"  (olha para a direita da câmera)
- Personagem B: eyeline_side = "off_camera_left"   (olha para a esquerda da câmera)
- Mantido consistente em todos os framings OTS/reverse
